# Tenant Workspace Routing

Select the numbered stage that matches the requested outcome. Load only the listed inputs. Write readable markdown outputs.

## Shared creative foundation

For brand, UX, story, campaign, documentary, production, approval, or learning work, load the applicable references from:

`../../shared/creative-operating-system/`

Required routing:

- discovery/research → `laws/human-centered-design.md` when present and `laws/nonprofit-trust-and-ethics.md`;
- landing page/brand → `laws/design-ux-and-brand.md`;
- campaign/message → `laws/story-documentary-and-production.md` and `laws/growth-offer-and-retention.md`;
- event capture/documentary → `laws/story-documentary-and-production.md` and `laws/nonprofit-trust-and-ethics.md`;
- approval → `REVIEW-GATES.md` plus all laws loaded by the producing stage.

Tenant-specific mission, voice, audience, safety, and campaign facts remain authoritative within their scope. Shared laws may not override law, consent, verified facts, or client restrictions.
