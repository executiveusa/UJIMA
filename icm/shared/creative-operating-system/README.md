# Social Purpose Creative Operating System

Version: 1.0.0
Status: shared reference layer

This library converts durable design, story, documentary, growth, nonprofit, and production principles into explicit instructions for AI agents. It is shared infrastructure for every tenant. Client-specific mission, voice, audience, safety, approvals, and campaign facts remain in each tenant workspace.

## Governing rule

Do not imitate organizations, campaigns, visual assets, slogans, or protected creative expression. Extract durable operating principles, verify them against the linked source material, and apply them in an original way appropriate to the client.

## Required loading pattern

Agents must load only the files needed for the active stage.

| Stage type | Required shared references |
|---|---|
| Discovery and research | `laws/human-centered-design.md`, `laws/nonprofit-trust-and-ethics.md` |
| Brand and landing pages | `laws/design-ux-and-brand.md`, `laws/human-centered-design.md` |
| Campaign strategy | `laws/story-and-message.md`, `laws/growth-offer-and-retention.md`, `laws/nonprofit-trust-and-ethics.md` |
| Documentary and event capture | `laws/documentary-and-production.md`, `laws/nonprofit-trust-and-ethics.md` |
| Approval | `REVIEW-GATES.md` plus every law used by the producing stage |
| Learning | the producing stage laws plus the tenant learning file |

## Authority order

When instructions conflict, use this order:

1. Law, youth safety, consent, privacy, and documented client restrictions.
2. Verified facts and signed approvals.
3. Tenant mission, brand, voice, and campaign source of truth.
4. Shared Creative Operating System laws.
5. Stage contract.
6. Creative preference.

A lower item can never override a higher item.

## Operating standard

Every artifact must identify:

- objective;
- primary audience;
- required action;
- evidence base;
- risks;
- success measure;
- approval requirement;
- source files used.

## Evidence standard

The organization names in `REFERENCES.md` are reference traditions, not endorsements. Some provide formal standards; others provide an observable body of work. Agents must distinguish:

- **Normative source** — official standard, guideline, policy, report, or documented method.
- **Practice reference** — a body of published work used for comparative study, not copied as a formula.
- **Secondary interpretation** — allowed only when primary material is unavailable and clearly labeled.

## Originality rule

Never request or produce work "in the style of" a living artist, filmmaker, photographer, agency, or protected franchise. Translate principles into neutral requirements such as restraint, clear hierarchy, truthful human detail, narrative tension, or evidence-led storytelling.

## Factory improvement

When reviewers make the same correction three times, log the pattern and propose a source-level update to a law, tenant configuration, template, or stage contract. Fix the factory when the problem is repeatable.
