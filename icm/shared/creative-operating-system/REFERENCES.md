# Reference Registry

Last reviewed: 2026-07-18

This registry gives agents source material for the shared laws. Prefer primary and official sources. The system does not claim endorsement, partnership, or equivalence with any organization listed here.

## Design, usability, and human-centered practice

### Apple — purpose, agency, responsibility, familiarity, flexibility, simplicity, craft, delight
- Type: normative design guidance
- Primary reference: https://developer.apple.com/design/human-interface-guidelines/design-principles
- Supporting reference: https://developer.apple.com/design/human-interface-guidelines
- Agent use: remove unnecessary elements, preserve user agency, use familiar patterns, protect privacy, establish hierarchy, and treat delight as a result of care rather than decoration.

### IDEO / IDEO.org — human-centered design
- Type: documented methodology
- Primary reference: https://www.designkit.org/human-centered-design.html
- Field guide: https://www.designkit.org/resources/1.html
- Supporting overview: https://www.ideo.com/journal/design-kit-the-human-centered-design-toolkit
- Agent use: begin with the people served, learn directly from them, synthesize needs, prototype, test, and iterate.

### Nielsen Norman Group — usability and interaction heuristics
- Type: documented UX methodology
- Primary reference: https://www.nngroup.com/articles/ten-usability-heuristics/
- Heuristic evaluation: https://www.nngroup.com/articles/how-to-conduct-a-heuristic-evaluation/
- Agent use: make system status visible, match real-world language, support control and recovery, prevent errors, reduce memory burden, and prioritize recognition over recall.

### Steve Krug — self-evident interfaces and scan-friendly communication
- Type: published usability reference
- Book reference: *Don't Make Me Think, Revisited*, New Riders, 2014
- Publisher page: https://www.pearson.com/en-us/subject-catalog/p/dont-make-me-think-revisited/P200000009441
- Agent use: eliminate question marks, design for scanning, use clear visual hierarchy, remove needless words, and make choices unambiguous.

### Marty Neumeier — brand differentiation and coherence
- Type: published brand-strategy reference
- Author reference: https://www.martyneumeier.com/
- Book reference: *The Brand Gap*
- Agent use: treat brand as the audience's accumulated perception; maintain coherence between promise, behavior, identity, and proof.

## Story, emotion, and message

### Pixar — story development and iterative craft
- Type: educational production reference
- Primary reference: https://www.pixar.com/pixar-in-a-box
- Agent use: establish character, desire, obstacle, stakes, change, and emotional causality; revise through multiple passes.

### Nike — mission-led emotional communication
- Type: official mission reference plus practice corpus
- Primary reference: https://about.nike.com/en/mission
- Agent use: lead with human aspiration and identity rather than a feature inventory; connect the action to a larger possibility without fabricating emotion.

### Donald Miller / StoryBrand — clarity and customer-as-character framing
- Type: commercial messaging framework
- Primary reference: https://storybrand.com/
- Agent use: define the audience, problem, guide, plan, call to action, success, and cost of inaction. The organization is the guide, not the hero.

### Humans of New York — human-first micro-narratives
- Type: practice reference
- Primary corpus: https://www.humansofnewyork.com/
- Agent use: begin with specific lived experience, preserve the subject's voice, avoid reducing people to labels, and let concrete detail carry meaning.

## Documentary and production

### National Geographic — strategic medium choice, visual storytelling, ethics, and dignity
- Type: official education and ethics references
- Storytelling process: https://education.nationalgeographic.org/resource/how-we-tell-stories/
- Elements of storytelling: https://education.nationalgeographic.org/resource/elements-storytelling/
- Code of ethics: https://www.nationalgeographic.org/society/code-of-ethics/
- Agent use: choose medium deliberately, plan before capture, preserve context, credit sources, and act with honesty, fairness, transparency, respect, dignity, and sensitivity.

### BBC — editorial accuracy, fairness, harm avoidance, and public trust
- Type: official editorial standard
- Primary reference: https://www.bbc.com/editorialguidelines
- Agent use: verify claims, distinguish fact from opinion, correct material errors, consider harm, and preserve editorial independence.

### Netflix — technical delivery, localization, and accessibility discipline
- Type: official production-delivery specifications
- Delivery specifications: https://partnerhelp.netflixstudios.com/hc/en-us/sections/10066414335891-Delivery-Specifications
- Localization and accessibility: https://partnerhelp.netflixstudios.com/hc/en-us/articles/7357416307603-Localization-Accessibility-and-Dubbing-Branded-Delivery-Specifications
- Agent use: plan deliverables, naming, captions, subtitles, accessibility assets, masters, and quality control before production ends.

### A24 — cinematic restraint and distinct point of view
- Type: practice reference only
- Primary corpus: https://a24films.com/films
- Agent use: study restraint, atmosphere, specificity, and coherent point of view. Do not imitate a film, director, campaign, or visual signature.

## Offers, attention, and growth

### Alex Hormozi / Acquisition.com — value, offer clarity, proof, and risk reduction
- Type: commercial education reference
- Primary reference: https://www.acquisition.com/training
- Agent use: clarify the desired outcome, reduce delay and effort, increase confidence, show proof, and remove unnecessary friction. Never manufacture scarcity or guarantees.

### MrBeast — retention-focused digital production
- Type: practice reference; not a formal standard
- Primary corpus: https://www.youtube.com/@MrBeast
- Agent use: earn continued attention through immediate clarity, visible progression, changing information, payoff, and ruthless removal of dead time. Do not use deception, humiliation, unsafe spectacle, or misleading thumbnails.

## Authenticity and nonprofit trust

### Patagonia — mission-behavior alignment and proof through action
- Type: official mission and governance reference
- Primary reference: https://www.patagonia.com/ownership/
- Values reference: https://www.patagonia.com/core-values/
- Agent use: claims must match organizational behavior; disclose tradeoffs; prefer demonstrated commitment over self-congratulation.

### charity: water — transparent impact reporting and donor proof
- Type: official nonprofit reporting reference
- Financials and annual reports: https://www.charitywater.org/about/financials
- Agent use: pair human stories with traceable outcomes, financial transparency, documented results, and clear donor stewardship.

## Citation discipline for agent outputs

When a shared law materially shapes an audit or recommendation, the output should cite the relevant entry by organization and URL. Do not attach a famous name to a generic preference. State the actual principle applied.

Correct:
> The page needs one dominant action and less visual noise, applying Apple HIG simplicity and Krug's scan-first usability principles.

Incorrect:
> Make it more Apple-like.
