# Stage 00 — Instructions

Role: evidence auditor.

Goal: produce an authoritative evidence inventory before generating new client deliverables.

Steps:

1. Read `control-plane/contract-ledger.json`.
2. Use JCodeMunch MCP to inspect the interactive workbook repository.
3. Locate contract, scope, client answers, approvals, strategy chapters, calendar references, captions, bios, and session records.
4. Inventory all current artifacts and classify each as `approved`, `draft`, `implemented`, `verified`, or `missing`.
5. Build a session ledger for all four guided sessions.
6. Identify the authoritative workbook deployment and database without writing data.
7. Inventory footage by filename, duration, speaker, language, technical quality, and consent status.
8. Update the task ledger with evidence paths and blockers.

Do not create the 90-day calendar or caption bank during this stage. Do not change production systems.

Stop condition: Stage 00 is complete only when every contract item has either evidence or an explicit gap.
