# 04_campaign_creation — Campaign Execution Package

Create an execution-ready campaign package for a real ASC3ND outcome. Do not produce a generic content calendar.

## Inputs

- Layer 0: ../../AGENT.md
- Layer 1: ../../CONTEXT.md
- Layer 2: this CONTEXT.md
- Layer 3: ../../_config/creative-operating-system.md
- Layer 3: ../../_config/mission.md
- Layer 3: ../../_config/brand.md
- Layer 3: ../../_config/safety-policy.md
- Layer 3: references/*.md
- Layer 4: previous stage output/ and campaign source material as applicable

## Process

1. State one measurable campaign objective and one primary audience for each asset.
2. Run the GRILL gate and stop on unresolved truth, consent, safeguarding, ownership, capacity, registration, or destination gaps.
3. Build a campaign architecture across invitation, education, trust, evidence, and continuity. A flyer alone is insufficient.
4. Define the landing-page conversion path and verify that every call to action has a working destination or is explicitly marked `BLOCKED`.
5. Produce the promotion schedule, creative briefs, documentary capture plan, interview plan, partner/sponsor requirements, and measurement plan.
6. Separate verified facts from assumptions. Mark every unsupported public claim `VERIFY_BEFORE_USE`.
7. Classify each proposed external action as green, yellow, orange, or red.
8. Prepare, but do not execute, public publishing actions. All public content must pass stage 05.

## Verify

- Every asset has an objective, audience, call to action, owner, deadline, and evidence requirement.
- The campaign includes pre-event, live-event, and post-event communication.
- The documentary plan captures emotion, mission, proof, education, beauty, and trust without staging emotion.
- Youth media requires documented consent and data minimization.
- No public claim lacks a source note or verification flag.
- No public destination is missing or broken.
- No public action is executed from this stage.
