# Backend Loop 08 — GitHub-Native Automation Fabric

## Acceptance gates
- Branch + PR + CI + conflict-check flow is explicit and machine-readable.
- Ralphy dangerous autonomy modes are denied.
- OpenHands is optional and bounded, never canonical memory.
- Firstmate supervises but cannot self-approve.
- Mission packets declare scope, risk, evidence, rollback and approval policy.
- Tier 3 actions require explicit human approval.
