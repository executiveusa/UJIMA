# Stage 04 Reference — Agent Pack Selection

Select skills case by case. Do not load every skill merely because it exists.

Core:
- `.agents/skills/digital-cofounder/SKILL.md`
- `.agents/skills/project-management-gtd/SKILL.md`

Conditional:
- nonprofit/social-purpose tenant -> `.agents/skills/nonprofit-strategy/SKILL.md`
- brand/marketing/story work -> `.agents/skills/brand-marketing-story/SKILL.md`
- website/app/flyer/poster/deck/form review -> `.agents/skills/krug-design-review/SKILL.md`
- local AI-native video editing -> `.agents/skills/synthcut-local-video/SKILL.md`

Portable manifest:
- `packages/agenix-master-agent-pack/agenix-master-agent-pack.json`

Agent-pack law: the workflow is consistent; the reasoning and solution must remain specific to the tenant, audience, outcome, risk, budget, culture, evidence, and maturity.
