# Groundwork — Done For You / Done With You Managed Agent Offer

## Positioning

Groundwork is not "an AI chatbot for nonprofits."

It is a guided operating and digital-readiness service that first establishes what is true, what is missing, what is unsafe to claim, and what actions will most improve the organization's ability to be found, trusted, funded, and operated.

ASC3ND is the reference implementation.

## Entry promise

**Give us the organization and its existing digital footprint. Groundwork finds the gaps, fixes what can be safely fixed, organizes what needs human authority, and leaves the organization with an AI assistant that understands how to keep the system healthy.**

## Phase 1 — Groundwork Audit

Agent-led research and evidence capture across:

- organization identity;
- legal/tax/public-record truth;
- website;
- accessibility;
- search/indexing;
- Google presence;
- Candid/GuideStar;
- nonprofit directories;
- social accounts;
- contact consistency;
- domain/email ownership;
- analytics;
- donation/fundraising readiness;
- grant readiness;
- program proof;
- event/project evidence;
- brand consistency;
- privacy/safety;
- youth/media-consent requirements where relevant;
- account ownership/recovery;
- operational documentation.

Output is a prioritized evidence-backed remediation plan, not a generic score.

## Phase 2 — Foundation Repair

Typical work:

- website corrections;
- search foundations;
- profile cleanup;
- truth/transparency page;
- brand-system consolidation;
- analytics;
- account ownership map;
- content-system setup;
- evidence organization;
- grant-readiness packet;
- Candid/Google readiness;
- intake/follow-up fixes.

Consequential registrations, legal/tax claims, submissions and public publishing remain human-gated.

## Phase 3 — Managed Instinct

Deploy a founder/operator-facing Instinct agent trained on the private ICM client brain.

It can:

- answer questions from approved organizational context;
- explain the next Groundwork step;
- research;
- prepare drafts;
- organize evidence;
- monitor missing items;
- prepare content;
- prepare grant workflows;
- coordinate bounded specialist agents;
- call supported tools and browser workflows;
- maintain an audit trail.

It cannot silently become an officer, publish consequential claims, submit legal certifications, move money, bypass consent, or change governance.

## Service modes

### Done For You

We operate the workflow.

Client responsibilities:

- provide/approve truth;
- complete identity/legal/banking verification directly when required;
- approve consequential public actions;
- attend scheduled review points.

We:

- run Groundwork;
- perform research;
- prepare/fix digital presence;
- configure the client brain;
- configure Instinct;
- connect approved integrations;
- build content operations;
- produce evidence and receipts;
- provide ongoing managed-agent support.

### Done With You

We build the system and train the client to operate it.

Includes:

- Groundwork audit;
- remediation plan;
- client-brain setup;
- Instinct setup;
- guided integrations;
- operating playbooks;
- approval workflow;
- content workflow;
- training;
- handoff;
- optional support retainer.

## Product boundary

The managed-agent offer does not promise:

- guaranteed grants;
- guaranteed donations;
- guaranteed search rank;
- guaranteed follower growth;
- autonomous legal/tax compliance;
- autonomous board/governance authority;
- fully autonomous social publishing by default.

The value is:

- reduced complexity;
- preserved organizational memory;
- fewer missed readiness steps;
- evidence-backed execution;
- repeatable operations;
- better continuity when staff/volunteers change.

## ASC3ND return presentation

Sequence:

1. "Here is what we originally promised."
2. "Here is what is complete and the proof."
3. "Here are the few items that need your confirmation to close the old engagement."
4. "Here is the website and evidence system you now own."
5. "Here is Groundwork, the next system we built from what we learned."
6. "If you want it, each of you gets an Instinct assistant that knows ASC3ND, follows the same guardrails, and can help you run the work without exposing the machinery."

Do not present Groundwork as necessary to receive the original paid deliverables.
