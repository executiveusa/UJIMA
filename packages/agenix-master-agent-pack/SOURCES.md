# Master Agent Pack — Sources and Provenance

## Purpose

This pack contains original operating rules synthesized from the owner's requested reference materials and current project operating experience. It intentionally avoids reproducing copyrighted source text or chapter-by-chapter substitutes.

## Derived areas

### Usability/design

The review skill applies high-level principles such as reducing unnecessary cognitive load, designing for scanning, clear hierarchy, plain language, obvious navigation/action, lightweight usability testing, mobile context, accessibility, and user courtesy.

### Project management / GTD

The project workflow combines outcome definition, next-action clarity, waiting/dependency tracking, recurring review, budget/schedule/scope baselines, change control, bounded work packages, and completion evidence.

### Brand / creativity

The brand skill emphasizes differentiation, focus, deliberate aesthetics, beauty as a quality yardstick, realistic prototyping/testing, simplification, and project-specific creative judgment rather than formulaic templates.

### Story / marketing

The story skill emphasizes audience relevance, attention, belief shift, emotional truth, credible future orientation, clear action, relationship value, and repeated testing/learning.

### Influence

Language patterns are treated as ethical communication tools for reducing friction and inviting decisions, never as permission for coercion, deception, false urgency, or concealed facts.

## Public-repository copyright rule

Detailed book-derived chapter notes should not be committed to this public repository unless redistribution rights are clear. If `book-to-skill` is used to create deeper study notes from copyrighted works, keep those generated notes in a private/local knowledge store and expose only high-level original decision rules to public shared skills.

## Refresh rule

Web-referenced technical projects such as SynthCut and book-to-skill must be refreshed from current upstream documentation before implementation because APIs, tool counts, installation methods, and architecture may change.
